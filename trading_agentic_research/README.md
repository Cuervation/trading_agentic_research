# Trading Agentic Research

Repositorio para research agéntico de estrategias de trading sobre S&P 500 / SPY.

## Qué contiene

- Estructura documental para agentes, skills y estado.
- Contratos iniciales para backtesting y comparación contra SPY.
- Esqueleto Python mínimo para el futuro motor de research.

## Qué NO hace todavía

- No descarga datos.
- No corre backtests.
- No promueve estrategias automáticamente.

## Filosofía

Este proyecto está pensado para gastar pocos tokens:

- Python hace el trabajo pesado.
- Los agentes leen resúmenes compactos.
- La decisión se toma con comparación explícita contra SPY.
